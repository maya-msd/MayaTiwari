# Maya Tiwari — Personal Portfolio

Clean, responsive personal portfolio website showcasing enterprise SAP ABAP engineering, S/4HANA MM configuration, and modern ABAP Cloud implementations. Built with pure semantic HTML, vanilla CSS, and minimal JavaScript. Published directly with GitHub Pages.

## Tech Stack
- **HTML5**: Semantic document structure
- **CSS3**: Custom responsive styling, CSS variables, zero framework dependencies
- **JavaScript**: Lightweight vanilla mobile navigation handler
